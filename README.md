# Week 10 – Sequelize

[![CI](https://github.com/jakobkorling/week10-sequelize/actions/workflows/ci.yml/badge.svg?branch=week12/ci)](https://github.com/jakobkorling/week10-sequelize/actions/workflows/ci.yml)

A REST API built with Express, TypeScript, Sequelize and PostgreSQL.

## Continuous Integration

GitHub Actions runs type checking and automated tests on Node.js 22, 24 and 26.

## Run locally

- `npm ci` – Install dependencies
- `npm run dev` – Start the development server
- `npm run typecheck` – Check TypeScript types
- `npm test` – Run tests
- `npm run build` – Build the project
